# Image Prompter Skill
When generating an image for this project, always:
1. Parse the CSS/Tailwind configuration files to extract active hex codes.
2. Use the "Subject + Context + Style" framework.
3. Automatically append the exact brand colors (e.g., "#1a202c primary, #e2e8f0 accent").
4. Specify the composition (e.g., "minimalist, shallow depth of field, 4k resolution").
5. Translate abstract web themes into literal, vivid descriptions.
